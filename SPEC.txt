============================= Instruction Set =============================
nop         : No OPeration
mov r, r/i8 : MOVe [ r = r/i8 ]
lda i16     : LoaD Address [ al,ah = i16 ]
stb r/i8    : STore Byte [ r/i8 -> al,ah ]
ldb r       : LoaD Byte [ al,ah -> r ]
push r/i8   : PUSH to stack [ sp-- = r/i8 ]
pop r       : POP from stack [ r = ++sp ]
adc         : ADd with Carry* [ x = a + b + f.carry]
and         : bitwise AND* [ x = a & b]
or          : bitwise OR* [ x = a | b ]
not         : bitwise NOT* [ x = ~a]
cmp         : CoMPare** [ f = a - b]
jmp         : unconditional JuMP [ pcl,pch = al,ah ]
bne         : Branch if NEgative [ pcl,pch = al,ah if f.negative]
bca         : Branch if CArry [ pcl,pch = al,ah if f.carry ]
bze         : Branch if ZEro [ pcl,pch = al,ah if f.zero ]
hlt         : HaLT

*    Updates flags
**   Result is discarded; flags are still updated

============================ Instruction Format ============================

Opcode global bit mapping: CCAAAAAA
    CC = 2 bits indicating which category the instruction belongs to
        no operands        = 0b00
        one operand        = 0b01
        two operands       = 0b10
        has 16-bit operand = 0b11

    AAAAAA = 6 bits for the respective arguments of each category

NO OPERANDS
    Opcode bit mapping: 00IIIIII
        IIIIII = 6 bits for the instruction index
            nop = 0b000001
            adc = 0b000010
            and = 0b000011
            or  = 0b000100
            not = 0b000101
            cmp = 0b000110
            jmp = 0b000111
            bne = 0b001000
            bca = 0b001001
            bze = 0b001010
            hlt = 0b001011

ONE OPERAND
    Opcode bit mapping: 01IIRRRR
        II = 2 bits for the instruction index
            stb  = 0b00
            ldb  = 0b01
            push = 0b10
            pop  = 0b11

        RRRR = 4 bits for the register index
            a     = 0b0000
            b     = 0b0001
            c     = 0b0010
            x     = 0b0011
            sp    = 0b0100
            f     = 0b0101
            al    = 0b0110
            ah    = 0b0111
            pcl   = 0b1000
            pch   = 0b1001
            imm8* = 0b1111

TWO OPERANDS
    Opcode bit mapping: 10IRRRRV XXXXXXXX
        I = 1 bit for the instruction index
            mov = 0b0

        RRRR = 4 bits for the register index
            a   = 0b0000
            b   = 0b0001
            c   = 0b0010
            x   = 0b0011
            sp  = 0b0100
            f   = 0b0101
            al  = 0b0110
            ah  = 0b0111
            pcl = 0b1000
            pch = 0b1001

        V = 1 bit for the type of the byte following the opcode
            register index = 0b0
                XXXXXXXX = 8 bits for the register index
                    a   = 0b00000000
                    b   = 0b00000001
                    c   = 0b00000010
                    x   = 0b00000011
                    sp  = 0b00000100
                    f   = 0b00000101
                    al  = 0b00000110
                    ah  = 0b00000111
                    pcl = 0b00001000
                    pch = 0b00001001

            8-bit immediate = 0b1
                XXXXXXXX = 8 bits for an immediate value

HAS 16-BIT OPERAND
    11IIIIII XXXXXXXX XXXXXXXX
        IIIIII = 6 bits for the instruction index
            lda = 0b000000

        XXXXXXXX XXXXXXXX = 16 bits for an immediate value

* special value indicating that the byte following the opcode is
  an 8-bit immediate

================================ Registers ================================
General Purpose (8-bit): a, b, c, x
    - "a" and "b" are always used for ALU operands
    - "x" always stores the result of ALU operations

Stack Pointer (8-bit): sp

Flags (4-bit): f -> - Z C N
                    | | | |
                    | | | +- Negative (LSB)
                    | | +--- Carry
                    | +----- Zero
                    +------- (unused) (MSB)

Address* (8-bit): al, ah

Program Counter* (8-bit): pcl, pch

* Stored internally as two 8-bit registers, but combined
  when put onto the address bus for use with memory access

============================== Memory Layout ==============================
Multi-byte values are stored in little-endian format

0x0000-0x7fff: Program Memory
0x8000-0x80ff: Stack (LIFO)
0x8100-0xffff: General Purpose
